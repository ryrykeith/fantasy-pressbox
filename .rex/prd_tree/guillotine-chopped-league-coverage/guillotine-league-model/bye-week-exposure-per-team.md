Network access was unavailable in that session, so a live Sleeper endpoint could not be checked either; docs/sleeper-data.md lists every endpoint currently called (league, users, rosters, matchups, transactions, traded_picks, drafts, draft picks, state, players) and none of them documents bye weeks.\n\nEverything else in the parent task shipped: src/analysis/danger.mjs (weekDanger, rollingFloor, buildDangerBoard) computes the survival margin, per-team chop-line distance, and rolling floor, wired into captureWeek's snapshot. Two candidate designs, in likely order of effort:\n\n1. Operator-declared bye table, mirroring config/guillotine.yml's eliminations: map exactly: a byeWeeks: block of nflTeam -> week (32 entries, published by the NFL months before the season, stable once written) that an operator fills in once per season. Lowest technical risk, no new HTTP surface, consistent with how this codebase already handles facts Sleeper cannot provide.\n2.
